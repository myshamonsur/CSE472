About the Event

SEU Tech Event is designed for students who want to learn about modern web development and basic technology concepts.

The main goal of this event is to help students improve their technical knowledge through simple and practical activities.

Event Venue

Department Computer Lab, Southeast University

Topics Covered

Core Topics

  • HTML and webpage structure
  • Web design basics
  • Lists, tables, and forms
  • Introduction to web development

Learning Sequence

  1. Understand webpage structure
  2. Create webpage sections
  3. Display information using tables
  4. Create a registration form

Detailed Plan

  • Week 1
    1. HTML skeleton
    2. Headings and paragraphs
    3. Links and images
  • Week 2
    • Lists
    • Tables
    • Forms
